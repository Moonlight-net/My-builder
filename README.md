# My Builder

A lightweight, browser-based drag-and-drop website builder featuring reusable page templates, editable elements, responsive canvas previews, local saving, and a preview mode.

## Run locally

Open `index.html` in a browser, or serve this folder with:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Custom domains

The **Connect domain** panel saves a domain and the DNS target supplied by a hosting provider in the current browser. This starter app does not host or publish websites, perform DNS verification, or provision HTTPS certificates. To make a custom domain live, publish/export the site to a hosting provider that supports custom domains, follow that provider's DNS instructions, and verify/enable HTTPS in its dashboard. DNS record types and targets vary by provider; use their exact values.
